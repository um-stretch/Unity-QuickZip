# QuickZip
A QuickMenu for .zip files in Unity.

## Features
* Extract in Place
* Zip in Place

## Limitations
* Folders and .zip files only

## Installation
QuickZip should be installed via Unity's package manager (using the repository's Git URL).
* [Here](https://docs.unity3d.com/6000.3/Documentation/Manual/upm-ui-giturl.html) is a tutorial on the Unity docs site.

## How to Use
QuickZip adds additional menu options when right-clicking objects in the Project window. Right-click a .zip file, then select QuickZip from the menu to access its features.
