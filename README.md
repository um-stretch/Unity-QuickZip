# UQuickZip
A QuickMenu for .zip files in Unity.

## Current Features
* Extract in Place
* Zip in Place

## Installation
UQuickZip should be installed via Unity's package manager (using the repository's Git URL).
* [Here](https://docs.unity3d.com/6000.2/Documentation/Manual/upm-ui-giturl.html) is a tutorial on the Unity docs site
